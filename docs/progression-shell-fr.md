## Executive summary

RentaLoc is a functional static PWA with a separated domain engine, runtime schema, dated ruleset, bounded/versioned persistence, robust validation, accessible dialog/live-region patterns, and pull-request CI. The current check command enforces 90% line, 95% function, and 70% branch coverage thresholds; exact current test counts belong in CI output rather than this roadmap.

The 2026-08-12 MVP audit is persisted in `docs/mvp-readiness-audit-2026-08-12.md`. The discovered 50-project silent-eviction path has been fixed with transactional persistence and regression tests. Repository-controlled production deployment and security headers are implemented for Cloudflare Pages.

Two external evidence/setup gates remain open:

1. **TQ-02:** a qualified French tax professional must independently approve the golden fiscal/reference fixtures.
2. Cloudflare/GitHub owners must create the Pages project, configure least-privilege secrets/environments/domain protections, and verify the first preview. Human screen-reader passes remain important under UX-04 but are not classified as a deployment P0 for this MVP.

The remaining Medium/Low roadmap is unchanged except where the High-priority work supplied part of its foundation. The app remains a simplified screening tool and must not be presented as tax, legal, or investment advice.

## Definition of done for backlog items

An item is not **Completed** until, where applicable:

- behavior and conservative fallbacks are documented;
- calculation changes have independent expected results and boundary tests;
- user flows include keyboard, mobile, invalid, empty, offline, and failure states;
- privacy/security implications are reviewed and no exact financial input is transmitted unintentionally;
- accessibility checks pass and manual checks are recorded;
- CI passes, documentation/source dates are updated, and the service-worker cache version is considered;
- this file is updated with the completion date and evidence (commit/issue/ADR).
